# 🛠️ Plumber Pro S.A. | Directorio de Profesionales

Una aplicación web profesional desarrollada en **React + Vite** para conectar a los mejores prestadores de servicios de Asunción, Paraguay, con sus clientes.

## 🚀 Características
- **Directorio Interactivo:** Búsqueda en tiempo real por nombre o rubro (Plomería, Electricidad, etc.).
- **Arquitectura SPA:** Navegación fluida sin recargas de página mediante React Router.
- **Diseño "Mobile First":** Totalmente responsivo y optimizado con Tailwind CSS.
- **Sistema de Registro:** Formulario dedicado para que nuevos profesionales se unan al equipo.

## 🛠️ Stack Tecnológico
- **Frontend:** React 18
- **Estilos:** Tailwind CSS
- **Enrutamiento:** React Router DOM
- **Build Tool:** Vite
